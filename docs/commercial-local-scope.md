# MarkFix 本地商业化展示版范围

## 目标

在不修改桌面端功能与交互的前提下，交付可以在本地完整演示的官网与管理后台。视觉语言延续桌面端的紫色标注品牌、克制的中性色和清晰的信息层级，交互组件统一使用仓库内的 shadcn/ui 组件层。

## 任务一：官网

### 要做

- 提供无需登录即可访问的官网首页。
- 展示 MarkFix 的核心价值、标注工作流、主要能力、团队协作场景和商业套餐。
- 提供进入管理后台、登录和下载桌面端的明确入口；本地展示版的下载按钮需明确标注为即将开放，不能伪装为真实下载。
- 支持桌面、平板和手机宽度的响应式展示。

### 不做

- 不接入支付、订单、订阅、客服、邮件营销或下载分发服务。
- 不承诺尚未实现的云端能力、浏览器兼容范围或安全认证。

### 验收标准

- `/` 可直接打开且不要求登录。
- 首页主要导航、核心行动按钮和后台入口可操作。
- 关键区域在 390px、768px、1440px 宽度下无横向溢出或内容遮挡。
- 页面使用共享 shadcn/ui 组件和统一设计令牌。

## 任务二：管理后台信息架构

### 要做

- 管理后台位于 `/app`，保留现有本地登录能力。
- 一级菜单包含“统计总览”“标注项目”“用户管理”。
- 统计总览展示项目总数、标注总数、待处理数和驳回数。
- 统计支持按项目维度和用户维度查看；用户维度必须展示其所属项目分类。
- 标注项目页展示当前工作区内的全部项目、项目分类、成员数、标注数和处理进度。
- 点击项目后，从右侧打开项目详情抽屉。

### 验收标准

- 菜单切换不会丢失当前工作区。
- 统计卡与维度列表使用同一数据源，筛选后数字一致。
- 项目抽屉可通过按钮、遮罩和 Escape 关闭，并具备可访问标题。
- 空数据、加载中和请求失败都有明确状态。

## 任务三：标注基础管理

### 要做

- 项目抽屉展示该项目下的全部标注及状态、类型、页面、提交人和更新时间。
- 支持新增、查看、编辑、删除和驳回标注。
- 驳回时必须填写原因；驳回信息可再次查看。
- 本地 API 持久化管理数据，并校验工作区成员权限；OWNER/ADMIN 可写，其他角色只读。
- 为本地演示数据提供项目分类与标注样例，不依赖桌面端产生数据。

### 验收标准

- CRUD 与驳回操作刷新页面后仍然存在。
- 不同工作区之间的数据严格隔离。
- 非管理角色的写请求返回 403，管理界面隐藏写操作。
- API 单元测试覆盖访问隔离、CRUD 和驳回原因校验。

## 完成定义

- 官网与管理后台在本地环境可连续演示。
- 相关类型检查、测试、构建通过。
- 最终 diff 不包含桌面端文件。
- 每个任务使用独立、可读的提交记录。
