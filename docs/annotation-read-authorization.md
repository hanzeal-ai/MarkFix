# 标注只读授权

用户在管理后台打开项目，展开“读取授权”，生成并复制授权地址。该地址只读开放授权用户自己在此项目提交的 `OPEN`、`FIX_FAILED` 标注，排除已驳回记录；团队管理员也不能通过该地址读取其他成员的标注。

地址有效期 90 天，可在同一位置撤销或重新生成。每位用户每个项目有一个授权，重新生成会使旧地址立即失效；地址只在生成时显示，之后无法找回原凭据。授权不能领取、修复、改状态或触发执行。授权用户失去项目成员资格后，读取也会失败。

授权地址包含 `#token=...` 片段。接收工具移除片段，将凭据放入 `Authorization: Bearer ...`，对地址执行 GET。不要把完整地址放入聊天、日志或公开页面。MarkFix 只保存凭据的 SHA-256 摘要。

接口 `GET /v1/annotation-feed/:grantId` 的用户和项目来自服务器授权记录，不接受 userId、projectId 或任意过滤条件。响应遵循共享 `annotationFeedSchema`，返回标题、问题说明、完整 captureBundle 上下文和来源链接，采用固定 50 条分页与 `nextCursor`。不复制原始图片文件，来源页面仍按登录身份校验访问。

## 数据变更与恢复

新增 Prisma 模型 `AnnotationReadGrant` 和增量迁移 `20260925000000_annotation_read_grants`，不修改既有用户、项目和标注。用户/项目删除时级联清理其读取授权，防止孤立授权。接口每次校验凭据、有效期和成员资格，并在查询后复查撤销/轮换状态。

生产迁移未在本轮执行。部署需先备份数据库并应用项目既定迁移流程，再发布配套 API/后台。回退可撤销授权后回退应用，保留新增表，不删除既有标注或修改状态；恢复新版本时确认原授权是否仍应有效。接收端已保存的数据不会因撤销授权而被远程删除。
