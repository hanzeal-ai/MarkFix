# Hanzeal 母站

源码位于 `sites/hanzeal/`，包含独立 HTML 和 CSS，不随产品 Dashboard 发布，也不在产品界面放置其他产品入口。

母站介绍产品矩阵与使用方式，产品本身保持独立。当前仍未确认线上 hanzeal.com 原始源码和站点根目录，不能将本目录视为已部署。发布前单独确认站点根目录、备份与缓存策略。

预览：`python3 -m http.server 4877 --bind 127.0.0.1 --directory sites/hanzeal`。

协作使用只读授权：数据源用户生成授权地址，接收方配置地址并主动拉取；数据范围由来源服务校验。原始图片仍在来源产品，拉取包含问题说明和标注上下文。母站可以介绍组合方式，产品内不相互推广。
