# 当前数据契约与升级边界

运行时只接受当前格式：桌面 SQLite user_version 3、captureBundle schemaVersion 2，以及包含完整页面、截图和元素 runtimeEvidence 的记录。本地 Agent 状态和云项目状态采用严格校验，旧授权字段、workspaceId 和旧绘图 annotations 不再被忽略或转换。

已有桌面 v0/v1/v2 或未来版本数据库会拒绝打开并保留原文件；不自动迁移或删除数据。旧本地 Agent 状态同样拒绝读取且不重写。需要另行授权数据维护后才能继续使用旧资料，不应通过清空配置绕过检查。

服务端 Report 是唯一批注来源。新迁移仅删除空的 ManagedAnnotation 表及枚举，旧记录或不符合当前契约的数据会使整个事务回滚。Report 与 ReportSubmission 的数据库约束继续阻止旧版本写入。历史 migration 保持原样以支持新库完整建表，不属于运行时兼容分支。

部署前必须独立审查目标数据、备份数据库及截图并取得部署授权；停止所有写入者后迁移。仓库脚本管理的 API 与后台会停止，额外部署的写入者需运维同步停止。失败后保持停服并前向修复，不自动降级。恢复旧版本需要匹配备份与镜像，并核对备份后的写入；详见 [部署说明](aliyun-deployment.md)。

sourceAnnotationId 仍允许为空，因为直接创建的 Report 可以没有本地批注来源。正常错误处理、平台适配与第三方网页兼容仍保留。本次代码清理不代表已迁移用户数据库或已部署。
