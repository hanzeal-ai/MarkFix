# 账户入口与危险操作体验验收

## 本轮范围

- 桌面端与后台共用浅色账户布局：中性底色、紫色主操作、清晰的内容与表单分区。
- 官网导航与首屏共用连续背景，收紧首屏顶部留白。
- 后台登录移除“返回官网”，旧后台登录组件复用现有账户入口。
- 密码显隐按钮由共享组件统一定位，消除两套 CSS 位移叠加。
- 桌面提供注册、找回密码、隐私政策和服务条款入口，在系统浏览器中复用现有账户页面。
- 删除项目使用红色危险按钮；默认聚焦取消，执行期间禁止重复确认，失败后保留弹窗。
- 创建项目失败使用 message，HTTPS 校验错误转换为中文，不展示 IPC 方法名。

视觉参考：[Vercel Geist](https://vercel.com/geist/introduction)、[Stripe Dashboard](https://docs.stripe.com/dashboard/basics)。采用克制的色彩、明确的层级与一致的控件位置，保留 MarkFix 的紫色品牌识别。

## 边界与风险

本轮未改变注册、验证邮箱、重置密码的服务端契约、数据结构或删除数据的业务语义。邮件投递继续使用已有 EmailPort。

桌面账户入口只接受四个固定页面标识，由主进程拼接到 `MARKFIX_DASHBOARD_ORIGIN`，默认 `https://markfix.hanzeal.com`。拒绝任意 URL、非 HTTPS 公网地址、带凭证或路径的源地址；仅允许回环 HTTP 用于本地验收。目标网站仍不能调用此入口。

删除确认从原生弹窗迁入受信任的桌面壳层，属于 R2 变更。已有主进程项目校验及服务端权限仍执行；弹窗显示时隐藏网站视图，避免原生视图覆盖确认操作。发布前仍需独立审查与人类批准，本记录不代表生产放行。

恢复方式：成对恢复删除确认 UI 与主进程原生确认，避免出现重复确认或缺少确认；按本轮修改逐项恢复账户入口与样式。无数据迁移。不可使用整目录重置覆盖工作区中的其他未提交修改。

## 可复现验证

使用 Node 24 与根目录声明的 pnpm 版本。

```sh
pnpm --filter @markfix/desktop exec vitest run tests/account-pages.test.ts
pnpm format:check
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm --filter @markfix/desktop exec electron scripts/smoke-account-ui.mjs
```

Electron 验收脚本创建临时用户目录和本地 API/网站夹具。账户接口、系统凭据库与浏览器打开动作使用测试替身，不接触真实账户或现有项目。脚本验证实际渲染界面、IPC、密码显隐和对齐、四个账户入口的目标、中文 message、红色删除按钮、取消与临时本地项目删除，并输出截图目录。可用 `MARKFIX_SMOKE_OUTPUT_DIR` 指定截图目录。

浏览器已目视检查官网、后台登录、注册与找回密码页面；登录密码按钮与输入框垂直中心偏差为 0，显隐切换有效。
