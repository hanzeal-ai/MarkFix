05 / Questions

开始之前。

必须同时安装三个产品吗？

不需要。CarryOn、DoTasks 和 MarkFix 都有独立用途。先完成当前任务，需要时再连接其他产品。

反馈者也需要安装开发工具吗？

只使用 MarkFix 收集页面反馈，不需要安装 Codex 或 Git。由实际修复者准备代码仓库与 AI 执行环境。

代码和截图会在哪里处理？

DoTasks 的代码工作在线上的流程管理下由本地 Agent 执行。MarkFix 支持本机和云端项目；云端协作会上传所提交的标注。模型执行会使用所配置的模型服务，具体数据范围请查看各产品说明。

如何了解费用与支持？

当前各产品的可用版本与套餐以对应产品页面为准。平台功能与模型账户费用应分别核对。团队试用和部署需求可通过邮箱联系，不提前承诺尚未提供的套餐能力。
